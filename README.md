# How_To_Waste_Four_Years

*如何浪费本科四年*

如题，该仓库用于记录本人将宝贵的本科四年都浪费在了什么地方。

如果你只是想看些实在点的东西，你找错仓库了，我后续会搞个没有废话只有成果的仓库，但至少不是这个仓库。

# 你是？
我是一名普通的2025级本科生。坐标安徽某211，不是合工大。看了十几年的动漫。现在的专业是机器人工程。

本人一直对IT技术有些说不上来的热情，恰逢当年人工智能大火，我看这东西用来搞动漫和3D建模之类的有两把刷子，于是就想梭哈计算机类专业——但是奈何分数尴尬只能在几个没听说过的专业里挑几个，最后录取到小保底去念统计学。志愿里填上这个统计学是因为有人说统计学是人工智能的数学基础，后来发现这行不适合我，数学分析真不是我应该碰的。

学了几个月就寻思怎么转专业了，后来恰逢我们这一届转专业政策改革，于是后来手忙脚乱火急火燎地备战转专业考试。

转成功了，大一也结束了，最大的收获是四级过了心态进步了，没学到什么专业知识。

转专业水很深，我不推荐所有人抱着“先进个好点大学的奇怪专业再去转专业”这个心态去填报志愿，这里面你自己无法控制的因素太多。

现在是机器人工程专业，选这个是因为从b乎了解到这个专业涉及到的工科知识面足够广，万一能碰上个自己喜欢又擅长的呢？

现在是2026年10月7日，国庆的最后一天，浅学了一个月的机器人工程，除了发现要学的东西还真有点多，也是没学到什么名堂没干出什么名堂。
