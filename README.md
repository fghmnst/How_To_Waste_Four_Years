# How_To_Waste_Four_Years

*如何浪费本科四年*

如题，该仓库用于记录本人将宝贵的本科四年都浪费在了什么地方。

如果你只是想看些实在点的东西，你找错仓库了，我后续会搞个没有废话只有成果的仓库，但至少不是这个仓库。

# 你是？
我是一名普通的2025级本科生。坐标安徽某211，不是合工大。看了十几年的动漫。现在的专业是机器人工程。

本人一直对IT技术有些说不上来的热情，恰逢当年人工智能大火，于是就想梭哈计算机类专业——但是奈何分数尴尬只能在几个没听说过的专业里挑几个，最后录取到小保底去念统计学。志愿里填上这个统计学是因为有人说统计学是人工智能的数学基础，真的上手去学才发现老实学数学太tm枯燥了，还是更乐意去搞点工程项目之类的。

学了几个月就寻思怎么转专业了，后来恰逢我们这一届转专业政策改革，于是之后就手忙脚乱火急火燎地备战转专业考试。

转成功了，大一也结束了，最大的收获是四级过了心态进步了，没学到什么专业知识。

转专业水很深，我不推荐所有人抱着“先进个好点大学的奇怪专业再去转专业”这个心态去填报志愿，这里面你自己无法控制的因素太多。

现在是机器人工程专业，选这个是因为从b乎了解到这个专业涉及到的工科知识面足够广，万一能碰上个自己喜欢又擅长的呢？

***
现在是2026年10月7日，国庆的最后一天，浅学了一个月的机器人工程，除了发现要学的东西还真有点多，也是没学到什么名堂没干出什么名堂。

***
现在是2026年11月20日，一个普通的周五。如果你真的看了我下文提到的AI辅助工作流的话，能注意到我使用了wsl。现在wsl已经不需要了，因为我真的在用linux，btw，Arch(我说CachyOS也是Arch)。

就是上个周末换的，其实最早在雨云租ubuntu服务器的时候就有在自己电脑上安装双系统的想法，浪费掉一整个愉快的半天周六后最后向wsl低头。

不得不说wsl真好用，如果只是暂时借用一下linux生态的话。

但wsl终究是没有linux物理机的灵魂，一是不能自由掌握整个系统的开销，二是大概是装不了什么桌面（我是rdp什么的都试过了，不行，而且没多大意义），所以一直有装linux双系统的念头。

之前为什么装linux双系统失败了？因为我装的是ubuntu24.04，理由是我最熟悉这个发行版，对其他发行版没什么概念。但真开始装的时候一直卡在安装引导那里，24.04和26.04以及不带图形界面的服务器版本都试过，ventoy进兼容模式加各种神秘启动参数也试过，换rufus写盘也试过，全部失败，当时真的道心破碎，后来问ai查b乎才知道我这台荣耀magicbook14pro就不该装ubuntu，（据AI所说）一是因为ubuntu不支持一些现代的硬件，二是因为我这台电脑的DSDT（ACPI表格）写得不规范，然后，然后就向wsl滑跪了。

回到小半年后的现在，我为什么这一回就成功了？

因为我改用了Arch（喜）。

准确地说是CachyOS，提到Arch主要因为是Arch梗多，CachyOS可比Arch本体少折腾太多东西了。

其实一开始是给我老家的一台老win10主机改成个人linux服务器，目前能想到的功能是开qbee帮我下一些冷门种子——再见绝望先生之类的——顺带为做种贡献自己的力量，，以及备份一些数据什么的。

我没选Debian，没选Ubuntu，我选了Arch，因为我有病。

晚上十点开始装，装到早上三点，所幸一回就成功了。

第二天我又起了给自己的笔记本装linux双系统的念头，了解Arch的时候得知了CachyOS，说这个发行版有着激进的性能优化和智能的驱动下载，对硬件的支持也新，就是这个了！这么想着就立即开干了。

比想象中顺利，CachyOS装起来可太省心了，不到一个小时就能顺利启动了。桌面我选的是hyprland，第一次打开的那一刻我就知道接下来我要用一辈子linux了——太tm漂亮了，太tm流畅了。

然后装了opencode，开始打磨这个新系统。

从上周日到现在每天都过着大块时间折腾新系统的新问题，碎片时间看中科大的linux101，其他时间看linux笑话的生活。btw中科大真是个好大学，要是当年多考个七八十分就好了。

现在这个系统已经高度可用了，我估计是能完全取代win了，之前提到的DSDT问题也被opencode配大肥鱼解决了，不过还是有些看不了风扇转速之类的小问题，我能接受就不打算解决了。

嘻嘻我要用一辈子linux。
